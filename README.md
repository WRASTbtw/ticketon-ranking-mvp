# Ранжирование витрин — MVP для Ticketon

Прототип системы, которая для каждого показа витрины подбирает и упорядочивает события
под посетителя и контекст, соблюдает правила бизнеса и логирует выдачу для обучения и A/B-тестов.

Все события, площадки, артисты и цифры синтетические; города настоящие. Даты считаются от момента открытия страницы.

## Что внутри

| Вкладка | Что показывает |
| --- | --- |
| Витрина | Текущий порядок «по ближайшему сеансу» рядом с порядком системы; 5 посетителей от нового гостя до авторизованного; клики пересобирают витрину; разбор оценки по сигналам; переключатели правил и имитация сбоя |
| A/B-симуляция | Синтетические посетители листают листинги категорий; конверсия, GMV, доверительные интервалы и побочные метрики |
| Лог выдачи | Запись, которая сохраняется на каждый показ: позиции, признаки, версия модели, propensity |
| О проекте | Коротко о подходе и о том, что синтетическое |

## Как устроен алгоритм

1. **Отбор**: из событий города убираются прошедшие, распроданные и закрытые.
2. **Оценка**: вероятность покупки × чек^α. Вероятность складывается из сигналов: спрос в городе, конверсия, скорость распродажи, удобная дата, выходные, клики визита, похожие события («кто купил это, купил и то»), история покупок, привычный чек.
3. **Правила**: склейка дублей, разнообразие категорий и площадок, места для исследования (новинки и редко показываемые события, выбор — сэмплированием Томпсона), закрепления и промо.
4. **Запасной порядок**: если сервис не ответил, витрина получает порядок по продажам в городе.

В MVP оценка — прозрачная формула с весами. На пилоте те же сигналы становятся признаками модели CatBoost, обученной на логах Ticketon.

## Файлы

```
index.html       страница
css/style.css    стили (светлая и тёмная тема, телефон)
js/data.js       генератор синтетического каталога и демо-посетителей
js/engine.js     движок ранжирования — не зависит от интерфейса, переносится в сервис
js/sim.js        симуляция A/B-теста
js/app.js        интерфейс
```

## Запуск

Сборка не нужна. Откройте `index.html` двойным кликом или поднимите любой статический сервер:

```bash
py -m http.server 8000
```

## Публикация на GitHub Pages

1. Создайте на GitHub пустой публичный репозиторий, например `ticketon-ranking-mvp`.
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "MVP ранжирования витрин"
git branch -M main
git remote add origin https://github.com/<логин>/ticketon-ranking-mvp.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/ticketon-ranking-mvp/`.
